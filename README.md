# Modelo de site pro app do Google

Modelo de página inicial e política de privacidade para quem usa o Segundo Cérebro com uma conexão própria do Google Cloud (Gmail, Drive, Agenda) e quer tirar o app do modo **Testing**, em que a autorização vence a cada 7 dias.

Este repositório não tem dados de ninguém. Os campos `{{NOME}}`, `{{NOME_DO_APP}}`, `{{EMAIL}}` e `{{DATA}}` são preenchidos na cópia que cada pessoa cria na própria conta do GitHub.

## Como usar

No Claude Code, dentro do seu vault, cole:

```
Abre https://github.com/danishiota10-code/template-site-app-google, lê o arquivo INSTRUCOES.md de lá e faz o que ele manda comigo, passo a passo.
```

Ele cria o seu site, publica o app no Google e refaz a autorização. Você só cria a conta no GitHub, responde quatro perguntas e clica em Permitir.

## Arquivos

- `index.html`: página inicial do app
- `privacidade.html`: política de privacidade
- `INSTRUCOES.md`: o roteiro que o Claude Code segue
